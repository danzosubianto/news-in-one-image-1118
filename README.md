The World Today — a program that draws a complete newspaper front page summing up the world news of Wednesday 18 November 2026 into a single 1024x1024 PNG: a drawn picture of the Gulf lead story (jets over Qeshm Island at dusk, the missile site under strike, drones answering) with its key numbers at a glance, six reported stories from across the regions — each with its own spot illustration: the Kerch Bridge's fallen span, the APEC flags, a Senate dome, the Ebola virus, a Star of David, Cyclone Xavier's spiral — and a black band of world briefs across the foot. Written in TypeScript on the Node standard library alone — its own hand-drawn bitmap typeface, software rasteriser and PNG encoder — it runs offline, reads nothing, and writes the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
